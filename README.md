# 🌟 Featured Projects

## 📄 Contract Risk & Compliance Reviewer

*Python • FastAPI • React • PostgreSQL/pgvector • Docker • AWS*

* Full-stack AI web app deployed on **AWS Lightsail** (Docker Compose, HTTPS via Caddy) that finds 8 types of contract clauses, rates each **Low / Medium / High** risk from the customer's side, and suggests safer wording
* Improved clause retrieval accuracy (**hit@1**) from **56.6% to 74.7%** and top-3 accuracy to **92.1%** on 357 development contracts from the 510 lawyer-annotated CUAD set (random baseline: 4.6%), using clause-aware chunking, BGE embeddings and BM25 hybrid search
* Added a **citation verifier** that checks every quote word for word, plus a "clause not found" check. Measured false-claim rate: **8.7% (4 of 46)**
* Tested a reranker and rejected it after it lowered hit@1 to 71.1%
* Secured with Argon2 password hashing, JWT login, per-user data isolation, upload limits and automatic deletion of old contracts
* Covered by **60+ automated tests**
* 🔗 [Live Demo](https://contractreviewer.duckdns.org) | [GitHub](https://github.com/khushalcodess/contract-reviewer)

## 🦺 SentryScan — Safety Helmet Detection System

*YOLOv8 • FastAPI • React.js*

* Real-time system that checks safety helmet compliance from images and live camera feeds, replacing manual on-site monitoring
* Trained on 28,000+ labeled images, achieving **91.8% mAP@50** and **88.4% Recall**
* Real-time inference at **2–5 ms per image**
* Audited the dataset and removed a noisy class to improve reliability
* Exported the model to **ONNX** for framework-independent deployment
* Deployed on Render and Vercel
* 🔗 [Live Demo](https://safety-helmet-detector.vercel.app) | [GitHub](https://github.com/khushalcodess/safety-helmet-detector)
